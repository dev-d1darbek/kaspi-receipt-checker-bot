## 🔍 Қалай жұмыс істейді

```
PDF → QR сілтеме → receipt.kaspi.kz → нақты деректер → салыстыру
```

Бот PDF-ке **сенбейді** — ол тек QR-ды тасымалдаушы. Тексеру Kaspi-нің нақты серверінен алынған деректермен жүреді. Сондықтан PDF-ті Photoshop-та жасау нәтиже бермейді: QR Kaspi базасында болмаса — чек қабылданбайды.

## 🧪 Тексеру тізбегі

```
┌─────────────────────────────────────────────────────────────┐
│ 1. Пайдаланушы PDF жібереді                                 │
└────────────────────┬────────────────────────────────────────┘
                     ▼
┌─────────────────────────────────────────────────────────────┐
│ 2. PDF-тен QR сілтеме алынады                               │
│    • Мәтіннен: regex receipt.kaspi.kz/web/fiscal?...        │
│    • Суреттен: cv2.QRCodeDetector (DCT/DPI 300)             │
└────────────────────┬────────────────────────────────────────┘
                     ▼
┌─────────────────────────────────────────────────────────────┐
│ 3. httpx.get(QR_сілтеме) → receipt.kaspi.kz                 │
│    ← Kaspi-нің нақты жауабы:                                │
│       amount, extTranId, ИИН/БИН продавца, РНМ, ФП, ЗНМ     │
└────────────────────┬────────────────────────────────────────┘
                     ▼
┌─────────────────────────────────────────────────────────────┐
│ 4. Төрт тексеру:                                            │
│    ✅ Чек Kaspi-де тіркелген бе                             │
│    ✅ Чек № PDF мәтінінде бар ма                            │
│    ✅ Компания БСН сәйкес пе                                │
│    ✅ Чек бұрын пайдаланылмаған ба                          │
└────────────────────┬────────────────────────────────────────┘
                     ▼
              ┌──────┴──────┐
              ▼             ▼
        ✅ Жарамды     ❌ Жарамсыз
      (чек сақталады)  (себебі көрсетіледі)
```

### Фейк чекті ұстау кестесі

| Жасалған чек түрі | Нәтиже |
|-------------------|--------|
| PDF-те QR жоқ | ❌ «QR табылмады» |
| Жалған QR (`fake.kaspi.kz`) | ❌ HTTP қате / 404 |
| Нақты QR, бірақ PDF өңделген | ❌ «Чек № PDF-те жоқ» |
| Нақты QR, басқа компания | ❌ «Басқа компания» |
| Барлығы дұрыс, бірақ бұрын жіберілген | ❌ «Чек пайдаланылған» |
| Барлығы дұрыс, бірінші рет | ✅ **Өтеді** |

## 🚀 Орнату

### Талаптар

- **Python 3.10+**
- **pip** және **venv**
- Telegram бот токені ([@BotFather](https://t.me/BotFather))

### 1. Репозиторийді клондау

```bash
git clone https://github.com/<username>/kaspi-receipt-checker-bot.git
cd kaspi-receipt-checker-bot
```

### 2. Виртуалды орта жасау

```bash
python -m venv venv

# Linux / macOS
source venv/bin/activate

# Windows
venv\Scripts\activate
```

### 3. Тәуелділіктерді орнату

```bash
pip install -r requirements.txt
```

> **Ескерту:** `opencv-python-headless` серверде GUI жоқ — жеңіл әрі жылдам. Егер жергілікті компьютерде `cv2` қате берсе, `opencv-python`-қа ауыстырыңыз.

### 4. Конфигурация

```bash
cp .env.example .env
```

`.env` файлын ашып толтырыңыз (төмендегі [Конфигурация](#-конфигурация) бөлімін қараңыз).

## ⚙️ Конфигурация

`.env` файлы:

```env
# Telegram Bot Token — @BotFather арқылы алыңыз
TG_BOT_TOKEN=1234567890:AAH...

# Админдердің Telegram ID-лері (үтір арқылы)
# Өз ID-іңізді @userinfobot арқылы біле аласыз
ADMIN_IDS=123456789
```

| Айнымалы | Міндетті | Сипаттама |
|----------|:--------:|-----------|
| `TG_BOT_TOKEN` | ✅ | BotFather-дан алынған токен |
| `ADMIN_IDS` | ❌ | `/reset` командасын қолдана алатын ID-лер |

> ⚠️ **МАҢЫЗДЫ:** `.env` файлын **ешқашан** Git-ке commit жасамаңыз — ол `.gitignore`-да бар. Токен ашылып қалса, бот бірден ұрланады.

## ▶️ Іске қосу

```bash
python bot.py
```

Сәтті іске қосылса, консольде мына хабарлама шығады:

```
🚀 Бот іске қосылды
```

### Жүйелік сервис ретінде (Linux, systemd)

`/etc/systemd/system/kaspi-bot.service`:

```ini
[Unit]
Description=Kaspi Receipt Checker Bot
After=network.target

[Service]
Type=simple
User=botuser
WorkingDirectory=/opt/kaspi-receipt-checker-bot
Environment="PATH=/opt/kaspi-receipt-checker-bot/venv/bin"
ExecStart=/opt/kaspi-receipt-checker-bot/venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now kaspi-bot
sudo systemctl status kaspi-bot
```

## 💬 Қолдану

### Командалар

| Команда | Сипаттама | Рұқсат |
|---------|-----------|:------:|
| `/start` | Бастау / компания күйін көру | Барлығы |
| `/status` | Сақталған компанияны көрсету | Барлығы |
| `/reset` | Компанияны тазалау | Тек админ |
| **PDF жіберу** | Бірінші рет — сақтау, кейін — тексеру | Барлығы |

### Жұмыс сценарийі

#### 🟢 Бірінші рет (компанияны орнату)

1. Пайдаланушы `/start` жазады
2. Бот: *«Алғашқы PDF чекті жіберіңіз — бот компанияны есте сақтайды»*
3. Пайдаланушы нақты Kaspi чегін жібереді
4. Бот:
   - PDF-тен QR-ды табады
   - Kaspi серверінен компания атауы мен БСН-ды алады
   - `settings` кестесіне сақтайды
   - Чекті «пайдаланылған» деп белгілейді
5. Хабарлама:
   ```
   ✅ Компания есте сақталды
   🏢 ХАДИША
   🔢 910420351008
   📄 Үлгі чек: 123456789012
   ```

#### 🔵 Кейінгі чектер (тексеру)

1. Пайдаланушы кез келген чек жібереді
2. Бот 4 тексеру жүргізеді:
   - Чек Kaspi-де бар ма
   - Чек № PDF-те бар ма
   - БСН сәйкес пе
   - Бұрын пайдаланылмаған ба
3. Нәтиже:
   ```
   🔎 Тексеру нәтижесі

   ✅ Чек Kaspi-де тіркелген
        `123456789012`
   ✅ Чек № PDF-те бар
        `123456789012`
   ✅ Компания сәйкес
        алынды `910420351008`, күтілді `910420351008`
   ✅ Чек жаңа
        `123456789012`

   ✅ Чек жарамды
   💳 Сома: 7,500 ₸
   🏢 Компания: ХАДИША
   ```

### `bot.py` ішіндегі негізгі функциялар

| Функция | Міндеті |
|---------|---------|
| `pdf_text()` | PDF-тен мәтін алу (pdfminer + pymupdf) |
| `pdf_qr()` | PDF суреттерінен QR декодтау |
| `find_qr_url()` | QR сілтемені табу (мәтін → сурет) |
| `kaspi_fetch()` | Kaspi бетінен чек деректерін алу |
| `extract_seller_info()` | Компания атауы мен БСН шығару |
| `_save_company()` | Бірінші чек — компанияны сақтау |
| `_verify_receipt()` | Кейінгі чек — 4 тексеру |
| `receipt_used()` | Чек бұрын жіберілген бе |
| `save_receipt()` | Пайдаланылған чекті сақтау |

## ❓ Жиі қойылатын сұрақтар

<details>
<summary><b>PDF жібергенде «QR табылмады» дейді — не істеу керек?</b></summary>

Чек Kaspi фискалдық чек болуы керек. Ескі чектерде QR болмауы мүмкін. Kaspi қосымшасынан **жаңа PDF чекті** жүктеп көріңіз (төлем тарихы → чек → «PDF ретінде жіберу»).
</details>

<details>
<summary><b>«Kaspi беті өзгерген» қатесі шықты</b></summary>

Kaspi өз сайтының HTML құрылымын өзгертті. `kaspi_fetch()` функциясындағы `__NUXT_DATA__` селекторын жаңарту керек. Issue ашыңыз.
</details>

<details>
<summary><b>Ботты бірнеше адам қолдана ала ма?</b></summary>

Иә. Бірақ компания **бір** (жалпы `settings` кестесінде). Егер әр пайдаланушыға жеке компания керек болса — `settings` кестесін `user_settings(user_id, key, value)`-ға өзгертіңіз.
</details>

<details>
<summary><b>Чекті қайта жіберуге бола ма?</b></summary>

Жоқ. Бірінші сәтті тексеруден кейін чек `receipts` кестесіне жазылады. Екінші рет «Бұрын пайдаланылған» деп қайтарады.
</details>

<details>
<summary><b>Компанияны қалай өзгертемін?</b></summary>

`/reset` командасын админ ретінде жіберіңіз. Келесі чек жаңа компанияны орнатады.
</details>

<details>
<summary><b>Дерекқор қайда сақталады?</b></summary>

`data/bot.db` — SQLite файлы. Backup үшін осы файлды көшіріңіз. Егер өшірсеңіз — компания мен чек тарихы жоғалады.
</details>
